# Agent Note: 提示词编辑显示当前内容；失败与经验可见

Status: implemented

[English](2026-09-10-prompt-editor-current-content-and-failure-log.md) | 中文

## Problem

卡片此前在一个字段里显示随包默认文本，因此已经覆盖过某段的部署看不到真正生效的内容，也分不清"覆盖"与"默认"。中文部署看不到自己实际发出的中文文本。`/correct-errors` 背后的失败与经验只能从文件系统访问。

## Decision

提示词编辑器只列出接受文本替换的段。选中段后，它会把英文 provider 当前文本、以及存在时的工作区翻译档案中文文本，分别直接填入两个可编辑字段。已有用户覆盖优先于这些基础内容。

同一卡片读取工具/MCP 失败日志和系统级经验文档。经验可编辑并保存回 `error-reflections.md`；失败日志保持只读，作为 `/correct-errors` 的证据。

## Verification

设置控制器、系统提示词和插件设置测试通过。重建 Web 后的新会话可以看到分别预填当前文本的中文和英文编辑框、失败列表和可编辑经验卡片。

## Alternatives considered

**只显示最终生效的覆盖内容。** 否决：需要对照两种语言的读者必须同时看到两侧；单字段会让"切换语言"变成破坏性操作。

**复用只读的提示词预览。** 否决：失败日志是证据、经验文档可编辑，只读预览两者都写不进去。

**让失败与经验留在会话记录里。** 否决：两者的生命周期都长于单个会话，而失败日志正是 `/correct-errors` 下一轮要读回的东西。

## Consequences

读者能看到下一次请求将携带的文本，并就地编辑任一语言；失败日志保持只读证据，经验文档保持可编辑。只列出可替换段让卡片保持诚实——它显示的每一项，都是覆盖真正能影响到的内容。
