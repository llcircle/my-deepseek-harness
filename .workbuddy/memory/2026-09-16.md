## `lean` e2e 收尾：33/33 全绿（技能可达性真 bug 修掉）

用户决策：① 本地发现**归宿主层**（承认现状，改测试）；② 预设自带技能用**宿主行加
`customSkillDirs`** 的方式挂（不把发现搬回预设层）。据此：

### 真 bug：预设自带技能不可达

`packages/skill/skill-filesystem/src/index.ts` 新增 `resolveCustomRoot`：`customSkillDirs` 额外接受
`file:` URL（`fileURLToPath`）。理由是预设会被 `copy()` 到任意目录，"资源在我旁边"无法用按 cwd
解析的路径表达，而 `baseUrl` 正是组合自身的 `file:` URL。

`packages/preset/agent-presets/presets/cordis/agent.cordis.yml` 在 `tool-skill` 前新增一行：
`providerName: cordis-preset` + `includeDefaultRoots: false` +
`customSkillDirs: !!js "[new URL('skills', baseUrl).href]"`（**必须是带引号的标量**：`JsExpr` 的
`kind: 'scalar'`，写成 flow 序列会报 `unknown tag`，整个组合挂载失败）。

### 一处被我推断错的语义（记下来别再犯）

我以为"预设层 provider 与宿主同名 `filesystem` 会顶掉宿主 → 预设 agent 丢项目/用户技能"，
按 `SkillRegistry` 类注释"就近层的同名条目整条胜出"推的。**写了断言去验，断言直接通过** ——
推断错了。真实语义：`NamedEntries` 只在**层内**查重（同层同名抛错），`collectFresh` 跨层是
`merged.set(candidate.name, entry)`，**去重键是技能名**。所以两个 provider 都会跑、候选按技能名合并。

即便如此仍显式起名 `providerName: cordis-preset`：同层撞名会硬抛错，且 `subagent-codex` README
的约定就是"每个已挂载实例需要唯一值"（先例：`isolated` / `codex-primary` / `acp-diagnostic`）。
