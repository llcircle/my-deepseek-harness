## 启动 Web 与浏览器 E2E
- **别用 `pnpm dsh`**：本机 shell 里 corepack 垫片会把 `/d/...` 拼成 `D:\d\Program Files\nodejs\...` 直接挂掉。用 `env -u NODE_OPTIONS node --import tsx/esm apps/cli/src/bin.ts --profile web --port <空闲端口> --no-open`（本机默认 3080 常被用户先前启动的实例占着）。启动行会打印带 token 的 URL；`GET /?token=…` 返回 303 + `set-cookie: dsh-auth-<id>=…`，把这一对 `name=value` 当 cookie 用即可调 Typert Remote。
- **Typert Remote 调用**：`POST /api/<namespace>/<method>`，body `{type:"client-request", rpcId, method, payload:{args:{…}}}`。**args 的字段名按 descriptor 来，不是按源码参数名**：`session/create` 与 `session/prompt` 要包一层 `request`，而 `settings/readPromptSections` 直接给顶层 `cwd`；多了 `_request` 会报 `unexpected "_request"`，少了会报 `missing "..."`。脚本：`.e2e/rpc.sh`。
- **agent-browser**：`open <url>` 单独跑完就退，守护随之消失，后续命令会另起空守护看到 `(empty page)`；必须把 `open` 与后续命令放在同一个 shell 生命周期里（`.e2e/e2e-step.sh`）。ref 只在同会话有效，要"先 snapshot 取 ref 再点"；不可见元素点击静默落空，先 `scrollintoview`。本机 Chrome 装在 `C:\Users\TDS\.agent-browser\browsers`。
- 会话日志 `session.v2.jsonl.zstd` 是多帧 zstd，按魔数 `28 B5 2F FD` 逐帧解（`.e2e/unzstd-frames.mjs`），`request/header` 事件带完整 `system`。
